# محدِّد نطاق المشاريع

دفتر مقابلة العميل: تختار نوع المشروع، تؤشّر على المميزات، وتخرج بالمدة والأدوات وعرض جاهز للعميل.

تطبيق ويب يُثبَّت على الهاتف (PWA)، بملف HTML واحد دون خطوة بناء.

## الملفات

- `index.html` : التطبيق كله (الواجهة، المكتبة، المنطق).
- `sw.js` : العمل بدون إنترنت. غيّر قيمة `V` عند كل تحديث.
- `manifest.webmanifest` والأيقونات : بيانات التثبيت.

## البيانات

المشاريع والإعدادات تُحفظ في متصفح الجهاز. خذ نسخة احتياطية من «إعداداتي» (زر الإعدادات أعلى الصفحة).
